# Workflow: tessl

Tessl is an Agent Enablement Platform that provides structured, versioned context to coding agents.

## Usage
- Run `tessl login` via terminal if the user asks to authenticate.
- Run `tessl init` via terminal to initialize a `tessl.json` manifest in the current directory.
- Use `tessl search <skill-name>` and `tessl install <skill-name>` to manage Tessl skills.
